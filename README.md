# N3uralia Image Enhancer — Historical Visual Intelligence Work

This repository is an **original N3uralia visual-enhancement experiment** from 2025–2026.

It is preserved as part of the engineering history that informed the broader preservation-first visual-intelligence work now represented by **Clar1ty**.

**Current product:** [clar1ty.art](https://clar1ty.art)

This repository is not the canonical Clar1ty product and should not be confused with the separate upstream `clarity-upscaler` fork that also exists on this GitHub account.

---

## What this generation explored

This implementation focused on practical image-enhancement workflows around:

- image upload and processing;
- before/after comparison;
- enhancement controls and quality-oriented UX;
- server-side model/API integration;
- responsive visual tooling;
- the boundary between restoration and generative alteration.

The most important product lesson from this work was that an enhancement system needs an explicit preservation policy. More detail is not automatically more truth.

That principle later became central to Clar1ty:

> **The source image remains authoritative.**

Identity, faces, textiles, artifacts, cultural details and other meaningful visual evidence should not be silently reinvented by an enhancement model.
